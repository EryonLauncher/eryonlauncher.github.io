# 🌿 Eryon Launcher

**Tu Minecraft. Tu experiencia.**

Eryon Launcher es un launcher de escritorio para Minecraft: Java Edition, diseñado para ofrecer una experiencia sencilla, moderna y personalizada.

## ✨ Características

- 🔐 **Inicio de sesión con Microsoft:** conecta tu cuenta para acceder a Minecraft Java Edition.
- 👤 **Gestión de cuentas:** guarda y administra perfiles de Minecraft.
- 🎮 **Selección de versiones:** consulta y selecciona versiones estables oficiales de Minecraft.
- ☕ **Gestión de Java:** comprueba la versión necesaria y prepara Java automáticamente en Windows cuando sea necesario.
- ⚙️ **Configuración personalizada:** ajusta la memoria RAM, la resolución, el modo de pantalla completa y otros parámetros.
- 💬 **Discord Rich Presence:** muestra tu actividad de Eryon Launcher y Minecraft en Discord cuando la integración está disponible.
- 📋 **Registros y diagnósticos:** guarda información útil para identificar problemas al iniciar el juego.

## 📥 Descargar

Descarga la última versión disponible desde la página oficial de versiones:

**[➡️ Descargar Eryon Launcher](https://github.com/EricCGO/eryon-launcher-releases/releases/latest)**

En la sección **Assets**, descarga el instalador para Windows cuyo nombre termine en `-Setup.exe`.

> Descarga el programa únicamente desde las publicaciones oficiales del proyecto.

## 💻 Requisitos

- Windows compatible con la versión publicada.
- Conexión a Internet para iniciar sesión y descargar los archivos del juego.
- Una cuenta Microsoft con acceso a Minecraft: Java Edition.
- Espacio libre en disco para el launcher y los archivos de Minecraft.

La versión de Java necesaria depende de la versión de Minecraft seleccionada.

## 🚀 Instalación

1. Descarga el instalador desde la página oficial de versiones.
2. Ejecuta el archivo `Eryon-Launcher-...-Setup.exe`.
3. Sigue las instrucciones del instalador.
4. Abre Eryon Launcher.
5. Inicia sesión con tu cuenta Microsoft.
6. Selecciona la versión de Minecraft que quieras utilizar.
7. Configura la memoria RAM y las demás opciones disponibles.
8. Pulsa el botón para iniciar Minecraft y espera a que termine la preparación inicial.

La primera ejecución puede tardar más debido a la descarga de archivos del juego y de sus dependencias.

## 💬 Discord Rich Presence

Eryon Launcher incorpora integración con Discord Rich Presence. Para mostrar tu actividad, Discord debe estar instalado y ejecutándose, y la integración debe poder conectarse correctamente.

La disponibilidad de la actividad puede depender de la configuración de Discord y de la versión del launcher.

## 🛠️ Solución de problemas

**El launcher no inicia Minecraft**
- Comprueba tu conexión a Internet.
- Verifica que tu cuenta tenga acceso a Minecraft: Java Edition.
- Comprueba que la versión de Minecraft seleccionada sea compatible con el Java requerido.

**No se conecta Discord**
- Abre la aplicación de Discord de escritorio.
- Reinicia Eryon Launcher.
- Comprueba que Discord permita mostrar tu actividad.

**Minecraft se cierra inesperadamente**
- Revisa los registros generados por Eryon Launcher.
- Comprueba que tengas suficiente memoria disponible.
- Verifica la compatibilidad de los mods si utilizas una instalación modificada.

## 🔒 Seguridad

Eryon Launcher utiliza el sistema de almacenamiento seguro de Electron para proteger las sesiones guardadas cuando el sistema lo permite.

No compartas tus archivos de sesión, credenciales ni registros si contienen información privada.
